# Kalam — ملفاتي (نسخة الويب)

واجهة ويب عربية باتجاه RTL لتطوير مساحة عمل قانونية تدريجيًا، بالاستناد إلى تحليل ملف APK الذي قدمه المستخدم.

## التشغيل
- افتح `index.html` في متصفح حديث أو انشر فرع التطوير باستخدام GitHub Pages.
- افتح قسم **ملفاتي والقضايا** من القائمة للوصول إلى `cases.html`.
- لا تحتاج النسخة الأولية إلى خادم أو حزم خارجية.

## الوظائف المتاحة حاليًا
### المكتبة القانونية
- إضافة النصوص القانونية والمواد والمذكرات والقرارات.
- البحث في المحتوى الذي أدخله المستخدم.
- الحفظ والتعديل والحذف والطباعة.
- تصدير واستيراد نسخة JSON محلية.

### ملفاتي والقضايا — نموذج أولي جديد
- إنشاء ملفات القضايا وتعديلها وحذفها.
- حقول رقم الملف، نوع القضية، المحكمة، القاعة، الأطراف، الخصم، القاضي المقرر، الحالة، الجلسة القادمة، الإجراء السابق والملاحظات.
- البحث في الملفات.
- طباعة بطاقة الملف.
- تصدير واستيراد نسخة احتياطية JSON خاصة بملفات القضايا.
- حفظ محلي في المتصفح عبر LocalStorage.

## ملاحظات مهمة
- المكتبة وملفات القضايا تستخدمان مخزنين محليين منفصلين في هذه المرحلة؛ لا توجد مزامنة تلقائية بين الأجهزة.
- لا تضع بيانات الموكلين الحساسة في جهاز مشترك أو متصفح غير محمي.
- تنبيهات Android وGoogle Drive والعمل في الخلفية ليست منجزة في نسخة الويب الحالية.
- قد تختلف صلاحيات المتصفح عن تطبيق Android؛ تُختبر كل ميزة قبل اعتبارها مكتملة.
- سجل تحليل APK وخطة النقل في `APK-FEATURE-AUDIT.md`.

## التطوير الآمن
- كل التعديلات في فرع `web-app-v1` بمستودع Kalam.
- مستودع Milafati مرجع للقراءة فقط ولا تُجرى عليه تغييرات.
- لا يُدمج طلب الدمج في `main` دون موافقة المستخدم.


## تحديث: ربط الجلسات والآجال بملفات القضايا
أضيفت إلى `cases.html` إدارة مواعيد مرتبطة بكل ملف:
- إضافة جلسة أو أجل إجرائي أو إجراء مطلوب أو موعد آخر، مع التاريخ والوقت والحالة والملاحظات.
- تعديل الموعد، ووضع علامة «منجز» أو إعادة فتحه، وحذفه.
- لوحة بالمواعيد المفتوحة خلال 14 يومًا، وعدّاد للآجال الإجرائية المتأخرة غير المنجزة.
- طباعة الملف مع قائمة الجلسات والآجال المرتبطة به.
- تنزيل موعد بصيغة `.ics` لاستيراده إلى تطبيق أجندة متوافق.
- النسخ الاحتياطي والاسترجاع يشملان المواعيد المرتبطة بالملفات.

### حدود التنبيهات
إشعارات المتصفح تتطلب إذنًا من المستخدم، ويجري فحص مواعيد اليوم عند فتح الصفحة. لا نضمن التنبيه بعد إغلاق الصفحة أو على كل أجهزة الهاتف، ولا تحسب الأداة الآجال القانونية تلقائيًا. يجب التحقق من كل أجل وفق الملف والقواعد القانونية المطبقة.
