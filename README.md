# Kalam — ملفاتي (نسخة الويب)

واجهة ويب عربية باتجاه RTL، كبداية لتحويل قدرات تطبيق ملفاتي على Android إلى تطبيق ويب.

## التشغيل
- افتح `index.html` في متصفح حديث، أو انشر المستودع باستخدام GitHub Pages.
- لا تحتاج النسخة الأولية إلى خادم أو حزم خارجية.

## الوظائف الحالية
- إدارة النصوص القانونية والمذكرات والقرارات.
- حقول التصنيف والمرجع والكتاب والقسم والباب والكلمات المفتاحية.
- البحث داخل المحتوى المدخل.
- حفظ العناصر وتعديلها وحذفها وطباعتها.
- تصدير واستيراد نسخة JSON احتياطية.

## حدود النسخة الأولية
- البيانات محفوظة في `localStorage` على الجهاز/المتصفح الحالي فقط؛ لا توجد مزامنة بين الأجهزة أو قاعدة بيانات سحابية.
- لا تتضمن النسخة الحالية قاعدة قوانين جاهزة أو استخراجًا آليًا من PDF/Word أو بحثًا دلاليًا.
- يلزم إجراء مقارنة تفصيلية مع ملفات التطبيق الأصلي للتحقق من تكافؤ جميع الوظائف. تمت مراجعة بيانات المستودع وملف إعداد Capacitor، لكن لم تتوفر جميع ملفات مصدر التطبيق الأصلي في الفحص الحالي.

## النشر
يمكن تفعيل GitHub Pages من إعدادات المستودع واختيار الفرع `main` والمجلد `/(root)`.
